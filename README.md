# background-mp3-repeater
Легковесное консольное Java-приложение для фонового воспроизведения MP3-файлов по строгому расписанию.
Изначально создано как инструмент для пассивного изучения языков (например, китайского или английского) и повторения технических концепций, но может использоваться для любых аудио-напоминаний.

## Возможности текущей версии (v1.0)
⏱ Точное расписание: Воспроизведение файлов в заданные часы и минуты.

📂 Конфигурация через JSON: Легкое добавление и изменение расписания без перекомпиляции кода.
