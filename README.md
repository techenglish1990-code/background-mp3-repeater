# background-mp3-repeater
Легковесное консольное Java-приложение для фонового воспроизведения MP3-файлов по строгому расписанию.
Изначально создано как инструмент для пассивного изучения языков (например, китайского или английского) и повторения коротких технических концепций, но может использоваться для любых аудио-напоминаний.

## Возможности текущей версии (v1.0)
+ ⏱ Точное расписание: Воспроизведение файлов в заданные часы и минуты.
+ 📂 Конфигурация через JSON: Легкое добавление и изменение расписания без перекомпиляции кода.

🚀 Как запустить
1. Через IntelliJ IDEA:
   + Убедитесь, что Maven зависимости загружены (нажмите иконку "Load Maven Changes").
   + Положите ваши .mp3 файлы в папку src/main/resources/audio/.
   + Настройте schedule.json.
   + Запустите класс Main.java.
   + Для остановки приложения нажмите Enter в окне консоли.
     
2. Через командную строку (Maven):
   ```bash
   mvn clean compile exec:java -Dexec.mainClass="dev.yenot.Main"
   ```
